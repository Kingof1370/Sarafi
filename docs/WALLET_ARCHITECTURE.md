# VELYXORA WALLET PLATFORM ARCHITECTURE

This document describes the design of the **Velyxora Wallet Platform** and transaction ledger engines under P004.

## System Workflow Diagram

```
  [ Client Request ] ===> [ REST API Gateway ] ===> Address Allocation & Audit
                                |
                                v (Secure Settle)
  [ Settle Balance ] <=== [ Wallet Service Ledger ] <=== Database ACID locking
```

## 1. Asset Registry Parameters
The platform operates on a dynamically registered asset registry (`types.Asset`) containing precision targets, minimum transfer constraints, and withdrawal network processing fees.

* Supported Assets: `BTC`, `ETH`, `BNB`, `USDT`, `USDC`, `TRX`, `SOL`, `TON`.

## 2. Dynamic Address Allocation
Deposit addresses are generated by mapping specific asset networks to custom validation profiles (`packages/common/blockchain.go`), preventing invalid outbound withdrawal mistakes.
