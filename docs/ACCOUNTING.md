# VELYXORA EXCHANGE - DOUBLE ENTRY ACCOUNTING MANUAL
Every matched trade is accounted for dynamically using dual-entry bookkeeping conventions:
- **Debit Entry:** Represents cost (Buyer quote debit, Seller base debit).
- **Credit Entry:** Represents delivery (Buyer base credit, Seller quote credit).
- **Platform Fee Account:** Collects dynamic Maker/Taker transaction fees.
