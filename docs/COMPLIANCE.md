# Compliance Framework Overview

Velyxora's Enterprise Compliance module is a fully integrated security and financial crime prevention system covering P0001 through P0009.

## Compliance Architecture
The platform integrates:
- **KYC Status & Profile Management**: Multi-tier limits validation.
- **AML Real-Time Monitors**: Alerts, rapid velocity detections.
- **Risk Assessment Scoring**: Fully explainable rules evaluations.
- **Fail-Closed Sanctions Screener**: Real-time address analysis.
- **Travel Rule Registry**: Mandatory originator and beneficiary checks.
- **Manual Investigator Cases**: Full manual reviews and audit trail notes.

All controls are backed by DB migrations and real-time Kafka event streams.
