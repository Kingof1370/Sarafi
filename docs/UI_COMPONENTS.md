# VELYXORA EXCHANGE - UI COMPONENT STANDARDS
This document outlines our professional dashboard widgets:
- **Order Ticket Panel:** Dual Buy/Sell buttons, Stop limit stop price fields, Iceberg Peak visibilities, and subtotal/commissions calculations.
- **Live Order Book:** Dual green (Bids) and red (Asks) queues, showing cumulative depth and spreads.
- **Recent Executions:** Dynamic feed showing trade direction, execution quantity, and timestamp.
